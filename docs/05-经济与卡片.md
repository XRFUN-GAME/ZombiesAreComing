## 直接购买规则（2026-11-05 站桩工作台制范式重写，docs/07 为准）

- 工作台左侧展示位摆实体模型，**直接触碰抓取**：手近悬停发光 → 捏合吸附即购买（扣款+Toast）
- 看向地面捏合放下 → 进入放置预览（0.5 米吸附，绿/青绿/红三态）；**拖回展示位全额退款；张掌扔掉退库存不退钱**（2026-11-05 去库存后：扔掉仅归位）；确认放置后不退货
- 抓起建筑自动收枪、抓起枪自动归还建筑（互斥全额退款）；建筑间直接换（差额结算）
- 钱不够置灰可悬停，捏合弹"金币不足"；倒地或高塔瘫痪时商店停用
- 旧"中控选择商品→全息预览"凝视 UI 已废弃（ShopPanel/ShopRow/ShopToast/WristMenu 2026-11-10 T7 清理移出）

## 抽卡规则（策划案 7.4 —— **T4 暂缓 2026-11-04 用户决策**，规则留档待回挂）

- 每次消耗 60 金币，随机展示 3 张不同卡片，选 1 张
- 稀有度权重：普通 70% / 稀有 25% / 史诗 5%
- **每第 5 次抽卡至少出 1 张稀有或更高**（保底）
- 被动卡同时最多 3 张，满后新卡必须替换旧卡
- 同名被动最多叠 2 层（标"不可叠加"除外）
- 主动卡独立卡槽最多 1 张，腕部菜单使用
- 所有卡片仅当局有效

## MVP 卡片范围（策划案 17.1）

M1—M2 只做 6 张：快速装填、赏金猎人、轻量建材、高效拓界、紧急屏障、应急重建。

## 实现要点

- `CardConfig : ScriptableObject` 保留（资产与生成器都在，T4 回挂即用）；卡片效果用效果修饰器模式（`ICardEffect`），按激活卡列表动态计算
- 抽卡随机数走本地随机种子（纯单机，可固定种子便于调试复现）
- 保底计数器每 5 次强制出稀有+
- 商店=工作台展示位（ShopStand，见 07）；倒地、高塔瘫痪状态屏蔽购买
