## 入侵敌方地盘（策划案 4.2）

- 越界：地面警示色 + "正在入侵"提示 + 视觉脉冲（无手柄震动，Swan 纯手势）

- 入侵伤害与僵尸伤害可叠加

## 交互范式（2026-10-30 重大变更：Swan 纯手势，无手柄）

**目标设备 Project Swan（PICO Space Pro）没有手柄，全部交互改为手势**。开发验证用 PICO 4 Ultra 的手势追踪（同 SDK 家族）。

手势方案（Vision Pro 式，全局统一）：
- **凝视 + 捏合（Pinch）**：视线落在目标上 → 食指拇指捏合 = 确认/购买/放置，捏住拖动 = 滑动/连续操作
- **右手掌心朝上停留**：原腕部菜单手势；**2026-11-05 暂撤：菜单下线，右掌停留暂无功能，M2-T4 主动卡时回挂**
- **张开手掌前推**：取消/关闭当前 UI（替代握持键取消）
- 射击 = 右手**食指伸直**（指向手势）；换弹 = 另一只手拍击弹匣位置
- **射击姿态（2026-11-03 第四次迭代定稿："食指伸直=开火"）**：右手**食指伸直**（指向手势）= 持续开火（一直伸直一直开，射速受武器配置约束）；食指弯曲（自然放松）= 停火。**右手捏合从射击语义中完全移除，仅作为确认/购买/放置等关键动作**——语义彻底解耦：指向=攻击、捏合=确认。命中判定默认走枪管方向（模式 B；按红线第 8 条，游戏内不可切换任何开发设置，瞄准模式只能出包前改 MoriSceneSetup.BuildAimMode 常量）；抬手胸前有效区判定保留（手不在有效区时食指伸直无效，防垂手误射）。手放下（低于腰部 1 秒）自动收枪待机。换弹=另一只手拍击弹匣位置（不变）。此姿态为全武器通用标准，后续武器沿用
- **持枪挂载（2026-11-05 站桩制修订）**：编辑器仍以手动摆好的手腕本地持枪位姿为准；运行时抓起即缓存该位姿并把真枪 root 重挂右手腕，放回时重挂到世界固定的工作台插槽锚点。不是只显示替身模型，归位后真枪实体必须固定在插槽
- **无触觉反馈**（Swan 无手柄无震动）→ 所有原来依赖手柄震动的提示改为：视觉脉冲（UI 边框闪烁）、音效分轨、手部模型高亮。策划案 13.3 触觉章作废
- **完全无移动/转向手势**（2026-11-06 起）：左右手侧推快速转向移除（误触率高，站桩制玩家完全固定）；传送与平移更早已废除（GestureLocomotion 整组件废弃留档）

## 站桩工作台制（2026-11-05 交互范式终稿：玩家固定，工作台前置）

**核心形态**：玩家**固定在工作台前**（不移动），面前弧形工作台（2026-11-06 实测 1.3 米够不着，**半径减半为 0.65 米**，伸手即可交互；绕玩家 180° 前向），所有交互都在工作台伸手即得范围内。守中布局 360° 受敌，僵尸从四面八方涌向工作台——**玩家是最后一道防线，站桩输出+建造防守**。

- **RealSpace 锚点制 + 高台输出位（2026-11-09 定稿）**：**RealSpace Y=塔顶渲染包围盒实测值=玩家脚位**（当前 1.5；玩家 XR 局部归零）；**工作台坐标=用户手管区（2026-11-09 用户定稿：RealSpace 局部 (0,0,0)，塔顶同高、台面≈玩家腰眼）——迁移只校验挂载、永不落位，审计只查碰撞自洽**；塔基座=射线实测视觉地面（当前 0.5）。地盘网格与刷怪圈以 RealSpace XZ 为世界锚（`MatchBootstrap.playSpaceAnchor` → `TerritoryGrid.WorldOrigin`；`WorldFloorY` 由地形射线实测）。**僵尸走视觉地面**：CUBE 地形瓦片批量加 BoxCollider+NavigationStatic（20557 块，迁移自动补齐），遗留全场景烘焙 agentClimb 0.6（普通台阶不阻拦）；工作台/高台/补给箱 NavMeshModifier 排除；**刷怪三重验证**（边缘随机+导航采样+从高台寻路连通，`ZombiePool.TryGetSpawnPosition` 8 次重试自动跳过悬浮/孤岛面——北向 12.5 米一处不可达为已知）。改塔高/地形后重跑迁移（`Builds/migrate-realspace.trigger`）自动跟随
- **工作台布局**（绕玩家前向 180° 弧形，从左到右）：
  - 左侧：**建筑展示区**（机枪塔 + 电网小型实体模型，抓起即用）
  - 中央：**操控区**（可留空或放信息面板）
  - 右侧：**枪械区**（应急手枪常驻插槽，抓起即装备）
  - 中央脚下：**高台（=旧中控职能）**：TowerVisual 灰盒 **1×1×1 米**（用户 2026-11-09 定稿，底面宽随尺度），基座贴实测视觉地面（0.5）、**玩家站塔顶输出**；塔有血量（CoreDevice 组件，1200），**僵尸主攻高台**（近战/酸液扣塔血），瘫痪/维修/结算口径全部适用；底面 1×1 米=**2×2 占地格**（随尺度自动计算，CoreDeviceFootprintCells）
- **完全不移动**：**传送手势废除**（左手掌上+捏合不再触发传送）；**快速转向废除**（2026-11-06：左右手侧推转 45°/90° 功能移除，GestureLocomotion 整组件不再挂载、代码留档可回挂）
- **拿起即用（零切换）**：抓起枪=立即装备开火（无"取出"步骤）；抓起建筑=立即吸附手上（拿起就走）
- **放下自动归位**：枪放回工作台插槽自动吸附复位（真枪 root 回原位）；建筑拖回展示位归位
- **地盘=可建造区域**：玩家不移动，地盘=建筑可放置的范围（安全区，僵尸进入后减速）；扩张=可建范围扩大（不变）
- **工作台补给箱**（2026-11-06 T5）：中央操控区开局 1 个，凝视+持续捏合 1.5 秒开箱，400—600 金币；开启后 120 秒原位刷新，倒地与对局结束时停止交互
- **枪械正式模型（2026-11-09 换装）**：枪械使用 `Assets/ArtAsset/Gun/MD_Pistol/Pistol.prefab`（HangGun.fbx，自带贴图，实例保持预制体链接），保留手腕关节挂载、手动位姿快照和插槽抓放链路；旧冲锋枪 `Sci-FiSubmachineGun/Gun.prefab` 退役（场景已移除，资源留档可回挂）。**Muzzle（枪口）/握持位姿沿用冲锋枪校准值**——手枪贴合或枪口火花位置不对时在编辑器手动微调 Muzzle/手腕位姿。旧中控大模型 `ZhongKong.prefab` 随站桩重构**退役**（Visual 禁用留档，prefab 内嵌 0.25 缩放原样保留，可回挂）
- **工作台碰撞与玩家一体承伤（2026-11-06；同日锚点化）**：工作台挂 RealSpace 局部 `(0,0,0)`、yaw 0（随玩家朝向 +Z）；根 BoxCollider `center=(0,0.365,0.55)`、`size=(1.56,0.73,1.10)`，NavMeshObstacle 同中心同尺寸且 carving。`playerRig` 继续负责追踪/枪械/重生，独立 `playerAttackTarget` 指向工作台；僵尸不能越过工作台直接打玩家，近战与酸液命中工作台均扣玩家生命
- **工作台形态定版：悬浮锚点制（2026-11-12 用户恢复并定稿）**：废实体台面视觉（弧板 9 段/腿 3 条/枪托板/展示位底板——实体版已备份 `Builds/SceneBackups/*-solid-20261112-094139` 与 `MoriMain-record-20261112-094149`），仅根 BoxCollider+NavMeshObstacle（承伤/防穿模零变更）。枪锚点右前 45°、建筑锚点左前 45°（机枪塔）/70°（电网），距 0.45 米、高 0.70 米，`AnchorFloat` ±1.5cm/1.5s 呼吸 + 淡金微光圈（AnchorRing，取出后留圈指引放回）；主场景与教学关双场景同步锚点化（迁移 `ApplyWorkbenchAnchors` + `ApplyWorkbenchAnchorsToTutorial`）

**地盘=安全区规则**（站桩制重定义）：

## 商店/仓库交互范式终稿（2026-11-05 定案：场景实体商店，废除腕部菜单 UI；同日修订：去库存化）

**核心交互 = 物理的"拿起来放下去"（Vision Pro 式）**：
- 中控台周围立**展示位**（当前两格：机枪塔 + 电网，各一个），展示位上是道具的**小型实体模型**（非 UI 面板）+ 浮空"名称 价格"标签（billboard）
- 手势流程（**直接触碰抓取**，Meta/Vision Pro 标准）：**右手伸向展示位模型，手腕/食指尖/中指尖就近点入 8cm 悬停区 → 模型微发光 + 浮空“捏合拿起”，置灰态也保留反馈**；右手捏合 = 抓起（模型吸附到手，跟手移动；边伸手边捏也不丢——悬停中捏合保持 0.25 秒兜底）→ **看向目标位置 + 捏合 = 放下**（进入放置预览，0.5 米吸附、绿/红合法性）→ 落地不再扣钱（**抓起即扣款**）。枪械插槽使用同一套 8cm 高亮与浮空提示。**不做远程凝视抓取**（展示位在手边，坐姿伸手即得；凝视不做主操作）
- **枪与建筑互斥**：成功抓起建筑时，若枪在右手，真枪自动归位工作台插槽；购买失败则继续持枪。抓起枪时，若右手有未落地建筑，建筑自动放回展示位并全额退款
- **建筑间直接换**：手上有旧建筑时抓新建筑不再拦截；购买预检按“当前金币 + 旧建筑全额退款”计算，成功后旧建筑自动归位、新建筑直接到手。账务公式：**切换后金币 = 切换前金币 + 旧建筑价格 − 新建筑价格**；若计入旧件退款仍买不起，则旧建筑与金币都保持不动
- **取消**（同日修订：无库存概念，未落地一律全额退款）：抓起后不想放 → **放回展示位**（拖回原位）/ **张掌前推扔掉** / 追踪丢失自动回位，三者都退全款；放置模式中张掌取消、封死通路回滚，同样退款
- **无库存概念（2026-11-05 用户决策）**：展示位模型是"货架样品"不是库存——**钱够就能抓**，不存在 ×N 库存数；模型**置灰 = 钱不够/达部署上限**，置灰态捏合给失败原因 Toast（金币不足等，不静默）
- **购买入口**：没有"购买"按钮——**抓起即购买**（展示位模型被拿起 = 扣款购买，进入放置流程）；简化极致
- **战斗状态不消失**：展示位常驻场景（不受对局阶段影响），战斗中想补建筑伸手就拿
- **仓库取消**：无仓库 UI、无库存页——已放置的道具在场景里可见即"仓库"
- **右掌上停留菜单暂撤（2026-11-05 用户决策）**：主动卡占位页不再呼出，腕部菜单整个下线；M2-T4 主动卡接入时按需回挂（WristMenu.cs 组件保留）
- **新手引导文案**：抓枪 → 射击一次 → 抓起建筑 → 看向地面捏合放下；侧推转身作为副行同步教学，不单独占步骤

**遗留**：原 ShopPanel/UI 代码（凝视检测/页签/Toast 等）与 WristMenu 组件标记 deprecated 保留可回挂，随 M2-T7 清理。

## 实现要点

- 玩家状态机：Alive → Downed(8s) → RespawnProtection(3s) → Alive
- 入侵判定 = 玩家坐标 → TerritoryGrid 查询归属（见 02）
- 中控状态机：Normal → Disabled(10s) → Recovered(40%)
- 重生保护提前结束：监听开火事件
- VR 边界：不自行绘制覆盖系统 Chaperone，只做游戏内地盘边界的地面贴花（实线己方/斜纹敌方/闪烁倒计时，见策划案 11.5 可读性：颜色+图案+图标三重编码，不单靠红绿）

## 新手引导四件套（M2-T0，2026-11-05 站桩制修订）
