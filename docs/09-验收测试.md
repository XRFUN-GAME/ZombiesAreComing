# 09 验收测试

> 每完成一个模块，运行对应条目自检。规则类测试必须写成 EditMode 单元测试（策划案 19.1）。

## 地盘规则测试（对应 CORE-07）

- [ ] 斜角地盘不触发接壤，四邻接触发
- [ ] 建筑圈地重叠面积不重复计分/计算
- [ ] 建筑销毁后，只中立化"失去来源且不连通"的网格外围
- [ ] 初始核心区在任何情况下不被夺取
- [ ] 失去归属网格上的建筑：离线 30 秒后销毁、不退款

## 破拆规则测试（对应 CORE-09）

- [ ] 破拆器不能选中控、超 2 米范围目标、未接壤目标
- [ ] 破拆全流程：放置 → 6 秒启动 → 销毁目标；防守方摧毁破拆器则中断
- [ ] 20 秒冷却与"同时最多 1 个"限制生效
- [ ] 取消摆放全额退款；已确认放置不能通过断线复制退款

## 经济规则测试（对应 CORE-05）

- [ ] 金币增减、购买取消、击杀分配（按伤害比例、最低 1 金币）、阶段奖励由权威层校验
- [ ] 多人打同一只僵尸：金币按比例分配、战斗积分归伤害最高者
- [ ] 抽卡保底：每第 5 次至少 1 张稀有+
- [ ] 被动卡 3 张上限、同名 2 层上限、主动卡 1 张

## 对局流程测试（对应 CORE-01、CORE-10）

- [ ] 8 分钟完整流程：阶段切换、解锁时点正确
- [ ] 倒地 → 8 秒重生 → 3 秒保护 → 主动射击提前结束保护
- [ ] 核心瘫痪：商店关闭、自动设施停用、地盘归属不变、10 秒后恢复 480
- [ ] 终局总分可用结算数据**逐项复算**（ScoreCalculator 纯函数）
- [ ] 平局依次比较规则正确

## 射击与武器测试（对应 CORE-03）

- [ ] 弱点倍率：普通 2 倍、督战者 1.5 倍
- [ ] 弹匣/换弹/武器槽/切换正确；无限后备弹药
- [ ] 枪械不伤玩家、不伤道具；能摧毁运行中的破拆器
- [ ] 霰弹枪 10 弹丸独立命中；电弧枪跳跃 2 次、对 Boss 不跳

## 僵尸测试（对应 CORE-04）

- [ ] 波次预算按表消耗、上限 18/人、全场 60、预算最多积两轮
- [ ] 阶段切换前 10 秒生成 -50%
- [ ] 蛮兽优先打设施；疾行者扑击可被霰弹枪打断
- [ ] 督战者只出现一次

## VR 实机测试项（策划案 19.2，需真机）

- 坐姿/站姿/左右手完成全部操作；不出安全边界完成移动建造射击
- 入侵、核心受击、破拆提示不遮挡瞄准与现实安全提示
- 连续 20 分钟晕动/疲劳/误操作记录

## 性能目标（策划案 19.3）

- 最低 72Hz 稳定；4 人 + 60 僵尸 + 设施上限 + 终局特效压力测试
- 150ms 延迟/抖动/丢包下射击、购买、破拆可用（M3 后）
