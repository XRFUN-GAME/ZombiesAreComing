# 10 音效与特效

资产化定稿（2026-11-11）：音效 `SfxLibrary.asset` + 背景 `bgm*` 字段 + 特效 `VfxLibrary.asset`，装配在 `ConfigAssetGenerator.CreateSfxLibrary/CreateVfxLibrary`；运行时经 `MatchBootstrap.Sfx / Bgm / Vfx`（SfxBus/VfxBus 门面）访问。**本文档 = 实际接线的唯一权威映射表**，改映射先改生成器再回写本文。

## 一、全局参数

| 项 | 值 | 出处 |
|---|---|---|
| 游戏音效音量 | 0.7 | SfxLibrary.sfxVolume |
| UI 音量 | 0.5 | uiVolume |
| 3D 声源衰减距离 | 15 米对数 | spatialMaxDistance |
| 命中/攻击 pitch 随机 | 0.95—1.05 | pitchMin/Max |
| 僵尸死亡同帧并发 | 3（超限静默） | deathConcurrentLimit |
| BGM 音量 / 交叉淡化 | 0.5 / 3 秒 SmoothStep | bgmVolume / bgmCrossfadeSeconds |
| BGM 紧张插曲概率 | 25%（至少隔 2 轮普通曲） | bgmTensionChance |
| 特效尺度修正 | 统一 0.4 起步（站桩 5 米场景，逐条目真机调） | VfxEntry.scale |
| 特效并发上限 | 爆体 6 / 溅血 10（超限丢弃最旧） | VfxEntry.maxConcurrent |
| 特效池化 | 一次性按 main.duration+startLifetime 自动回池；循环挂宿主随启停 | VfxPool |
